Cara membuat token (sekali saja)
  1. Login ke GitHub dengan akun pemilik repo, buka Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: misalnya Admin website. Expiration: pilih sesuai kebutuhan (misal 1 tahun).
  3. Repository access: pilih Only select repositories → virdtec-website.
  4. Permissions → Repository permissions → Contents: pilih Read and write.
  5. Klik Generate token, salin token (diawali github_pat_) lalu tempel di atas.

Simpan token seperti password. Jangan dibagikan. Token hanya bisa mengubah repo website ini.
